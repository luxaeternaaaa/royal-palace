# Royal Palace · Астана

Адаптивный демонстрационный сайт для презентации владельцам. Главная с фотографией зала → три зала и галерея → «Обсудим ваш праздник» с кнопкой «Примерная стоимость» и семью шагами → результат и предпросмотр сообщения → WhatsApp. Калькулятор умножает число гостей на бюджет посетителя; актуальные тарифы ресторана пока не заданы. Дата, помощь с организацией и пожелания необязательны. Кнопка «Назад», закрытие и повторное открытие сохраняют ответы до перезагрузки страницы. Обычная форма обращения и быстрые запросы меню/фото/просмотра работают независимо от калькулятора. Есть компоновки для компьютера и телефона.

## Запуск

Требуется Node.js 22 или новее. Установка пакетов не нужна.

```sh
npm run dev
```

Откройте http://localhost:4173. Сервер слушает только локальный компьютер.

```sh
npm test
npm run check
npm run build
```

Сборка находится в `dist/`. Её можно обслуживать любым статическим хостингом. Для локальной проверки сборки: `node scripts/serve.mjs --production` (предварительно остановить dev-сервер).

## Файлы

- `public/index.html` — содержание и семантическая разметка.
- `public/styles.css` — дизайн, токены, desktop/mobile и reduced motion.
- `public/app.js` — меню, выбор события, галерея, форма и диалоги.
- `public/cost.mjs` — проверка ответов, расчёт пользовательского бюджета и сообщение из калькулятора.
- `public/motion.mjs` — необязательные однократные появления блоков при прокрутке.
- `public/planner.mjs` — проверка данных, дата Астаны, сообщение и WhatsApp URL.
- `public/assets/` — фотографии площадки и локальные шрифты.
- `tests/planner.test.mjs` — проверки основного сценария и пограничных значений.
- `docs/asset-sources.md` — проверенные источники фото и контактов.
- `docs/verification.md` — фактические результаты проверки.
- `docs/design-review.md` — подтверждённые UX-проблемы, внешние источники и применённые критерии против шаблонного дизайна.
- `docs/logo-source.md` — происхождение подлинного логотипа.
- `DESIGN.md` — визуальные и поведенческие решения.

## Ограничения демо

Блоки мягко появляются при прокрутке, фотографии и кнопки реагируют на наведение, меню и FAQ плавно раскрываются в поддерживающих браузерах. Настройка уменьшения движения отключает декоративные эффекты. Главный экран и поля формы доступны сразу; отказ модуля анимаций не скрывает содержание и не мешает работе формы.

Меню пока не опубликовано: это прямо указано в компактном разделе с кнопкой запроса актуального предложения. Пустые категории и повторная инструкция подготовки убраны после независимого аудита. Конкретные блюда, цены, пакеты и включённые услуги не придуманы. FAQ объясняет доступность даты, запрос расчёта и просмотр зала. План качества и оставшиеся вопросы — в `docs/quality-plan.md`.

При отключённом или не загрузившемся JavaScript мобильная навигация остаётся доступной, фотографии открываются обычными ссылками, рядом с выключенной формой есть пояснение и прямые контакты. Галерея поддерживает точное 2× увеличение и восстановление карточки после сетевой ошибки. Результат последнего пользовательского аудита: `.design/critical-review-report.md`.

Сайт не подтверждает бронирования и ничего не отправляет автоматически. Данные формы не сохраняются. Только после явного нажатия откроется WhatsApp с подготовленным текстом; отправку пользователь выполняет там сам. Телефон и WhatsApp сверены с публичными карточками заведения. Три зала подтверждены пользователем; основной зал — на главном фото. Актуальная вместимость: основной — 550 мест, орта (средний) — 144, кіші (малый) — по запросу. Работающий в Royal Palace пользователь 21 октября 2026 года уточнил, что названные им 144 места относятся к среднему залу, а не к малому. Это последнее исправление имеет приоритет над его прежней оговоркой о малом зале и старыми 500/140 местами в Instagram. Вместимость малого зала не подтверждена; число ему не присваивать. История источников сохранена в `docs/asset-sources.md`.

Короткие запросы не читают и не меняют заполненную форму. Общий запрос не добавляет просьбу о просмотре без выбора пользователя. Если WhatsApp недоступен, текст можно скопировать; при запрете буфера обмена он выделяется для ручного копирования. Без JavaScript форма не отправляется, а быстрые ссылки содержат подготовленный текст. Текущие цены и оснащение без подтверждения не заявлены.

На странице используются лёгкие локальные WebP-превью, в увеличении — JPEG-оригиналы. Добавлен новый кадр интерьера из альбома владельца и ссылка на его видео без автозагрузки. Фотографии принадлежат их правообладателям: источник — галерея Royal Palace в 2ГИС, сведения сохранены в `docs/asset-sources.md`. Перед публикацией согласуйте материалы и текст с владельцами. Заголовки оформлены шрифтом Forum, тексты и элементы управления — Golos Text. Шрифты размещены локально и распространяются под OFL; лицензии приложены рядом с файлами шрифтов.

Перед рабочим запуском: подтвердить контактный номер, актуальные фото и разрешения на использование, рассадку для конкретного события, меню/стоимость, услуги, порядок просмотра и бронирования. Демо помечено в подвале и закрыто от поисковой индексации. Внешней публикации в этой задаче нет.

Текущее оформление — молочный фон, тёплый тёмный текст и золотые акценты. По последнему требованию пользователя фотографии с людьми не используются, включая фон и фрагменты людей; перед отбором проверяется исходник целиком.
