# Royal Palace · Астана

Адаптивный демонстрационный сайт для презентации владельцам. Главная с фотографией зала → залы и галерея → меню → услуги → обращение к администратору. В меню сначала выбирают тип: банкетное, новогоднее, выпускное или ас беру. Для банкетного и новогоднего затем выбирают зал. Все варианты показаны сразу: цена, целый лист, «Открыть меню». На телефоне это компактный список с миниатюрами. Состав открывается в текстовом просмотре; условия находятся в мелкой сноске внизу листа и текстового просмотра.

В «Обсудим ваш праздник» бюджет считается на одном экране: число гостей × собственный бюджет на гостя. Результат обновляется сразу; неверный ввод убирает прежнюю сумму. Расчёт не выбирает тариф и не добавляет услуги. Бюджет и обычное обращение сохраняют отдельные черновики до перезагрузки страницы. Дата и гости видны сразу в обычной форме и остаются необязательными; зал и пожелания — в дополнительных деталях. Любое обращение открывает проверяемый текст перед ручным переходом в WhatsApp.

Доступны русский, қазақша и English: переключатель RU / ҚАЗ / EN меняет интерфейс, листы и состав меню, ошибки и подготовленные сообщения. Ссылки `?lang=ru`, `?lang=kk`, `?lang=en` открывают нужный язык. Текущие ответы и выбранная цена сохраняются при переключении; пожелания посетителя не переводятся. В хранилище записываются язык и тема оформления. Без JavaScript остаётся русская HTML-версия с 21 ссылкой на листы. Названия залов переведены на выбранный язык. Цвета и бумажная фактура листов взяты из оригинальных PDF; состав среднего зала за 38 000 ₸ приравнен к малому по прямому уточнению пользователя, без переноса ограничений по вместимости и услуг.

## Запуск

Требуется Node.js 22 или новее. Для локального запуска и сборки установка пакетов не нужна. Для автоматических браузерных проверок нужны только инструменты разработки:

```sh
npm ci
npx playwright install chromium
```

В Linux с недостающими системными библиотеками: `npx playwright install --with-deps chromium`.

```sh
npm run dev
```

Откройте http://localhost:4173. Сервер слушает только локальный компьютер.

```sh
npm test
npm run check
npm run build
```

`npm test` запускает unit-проверки и сценарии Playwright на ПК и телефоне. Они используют отдельный локальный порт и не отправляют сообщения. `npm run test:unit` запускает только unit-проверки.

Сборка находится в `dist/`. Сборщик заново создаёт эту папку, чтобы удалённые ресурсы не оставались в выпуске; символические ссылки и junction вместо `dist` отклоняются. Её можно обслуживать любым статическим хостингом. Для локальной проверки сборки: `node scripts/serve.mjs --production` (предварительно остановить dev-сервер). Локальный сервер сжимает текстовые ресурсы gzip; на внешнем хостинге сжатие настраивается отдельно.

После изменения примечаний или условий меню выполните `node scripts/menu-design/sync-footnotes.mjs`: он обновляет невидимые описания карточек для экранных дикторов из общей модели. Сами условия напечатаны мелким текстом внизу листов и текстового просмотра; отдельного раскрытия под карточками нет. Листы пересобираются `node scripts/menu-design/render.mjs <путь-к-tooling/node_modules>` при запущенном локальном сервере. Полный лист с условиями и описание ссылки доступны и без JavaScript. Мобильная навигация также работает без JavaScript, через нативный `details`.

Мобильные изображения собираются `node scripts/media/prepare-images.mjs <путь-к-tooling/node_modules>` с установленным Sharp. Полные мобильные копии шести роликов собираются `scripts/media/prepare-mobile-videos.py`; параметры доступны через `--help`. Подлинные исходники сохраняются. Источники и фактические замеры — `docs/asset-sources.md` и `docs/verification.md`.

Нажатие на видео открывает плеер и запускает воспроизведение. На ПК сцена16:9, на телефоне портретный ролик сохраняет9:16; нативный горизонтальный файл заполняет кадр своих пропорций на обоих экранах. Обрезки и растяжения нет. Уровень громкости и mute сохраняются между роликами в пределах страницы; на устройствах с системным управлением громкостью вместо ползунка есть короткая подсказка. Закрытие останавливает и выгружает ролик, возвращая фокус.

## Файлы

- `public/index.html` — содержание и семантическая разметка.
- `public/styles.css` — дизайн, токены, desktop/mobile и reduced motion.
- `public/app.js` — меню, выбор события, галерея, форма и диалоги.
- `public/menu-data.mjs`, `public/menu-locales.mjs` — подтверждённые составы меню и их переводы.
- `public/occasion-menu-data.mjs`, `public/occasion-menu-locales.mjs` — новые предложения на Новый год и выпускной из 11 PDF.
- `public/cost.mjs` — проверка ответов, расчёт пользовательского бюджета и сообщение из калькулятора.
- `public/motion.mjs` — необязательные однократные появления блоков при прокрутке.
- `public/planner.mjs` — проверка данных, дата Астаны, сообщение и WhatsApp URL.
- `public/assets/` — фотографии площадки и локальные шрифты.
- `tests/planner.test.mjs` — проверки основного сценария и пограничных значений.
- `docs/asset-sources.md` — проверенные источники фото и контактов.
- `docs/verification.md` — фактические результаты проверки.
- `docs/design-review.md` — подтверждённые UX-проблемы, внешние источники и применённые критерии против шаблонного дизайна.
- `docs/logo-source.md` — происхождение подлинного логотипа.
- `DESIGN.md` — визуальные и поведенческие решения.

## Ограничения демо

Блоки мягко появляются при прокрутке, фотографии и кнопки реагируют на наведение, меню и FAQ плавно раскрываются в поддерживающих браузерах. Настройка уменьшения движения отключает декоративные эффекты. Главный экран и поля формы доступны сразу; отказ модуля анимаций не скрывает содержание и не мешает работе формы.

В «Меню» — 21 предложение: девять прежних из PDF, подтверждённый пользователем вариант среднего зала за 38 000 ₸ и 11 новых. Новогодних вариантов по три на каждый зал; выпускных два, за 37 000 и 42 000 ₸. Зал выпускного в источниках не указан. Отдельных меню на день рождения или корпоратив в PDF нет. Новогодние цены включают звук, свет, LED-экраны, фуршет и оформление; в выпускных оборудование указано отдельно за 1 000 000 ₸. Условия о мясе заказчика и напитках применяются только к тем предложениям, где они подтверждены. В файле `60.000  (1).pdf` напечатано 55 000 ₸: сайт использует печатную цену; расхождение нужно уточнить у владельцев.

Листы набраны Forum/Golos и отрендерены в 2400 px. Превью800px и русские мобильные листы640px собираются `scripts/menu-design/render.mjs` из тех же данных, что текстовый просмотр. Соседние новые листы выровнены по высоте для каждого языка. В окне видны категории и блюда без описаний ингредиентов; условия и примечания соответствуют выбранному предложению. Цена переключается только внутри того же типа меню и зала. WhatsApp открывается через проверяемый текст. Исходные PDF не меняются и не публикуются ссылками. Услуги остаются отдельным разделом по залам. Скриншоты и проверки этой задачи — `output/new-menu-pdfs/`; происхождение данных и фактур — `docs/menu-sources.md`.

При отключённом или не загрузившемся JavaScript мобильная навигация остаётся доступной, фотографии открываются обычными ссылками, рядом с выключенной формой есть пояснение и прямые контакты. Галерея поддерживает точное 2× увеличение и восстановление карточки после сетевой ошибки. Результат последнего пользовательского аудита: `.design/critical-review-report.md`.

Сайт не подтверждает бронирования и ничего не отправляет автоматически. Данные формы не сохраняются. Только после явного нажатия откроется WhatsApp с подготовленным текстом; отправку пользователь выполняет там сам. Телефон и WhatsApp сверены с публичными карточками заведения. Три зала подтверждены пользователем; основной зал — на главном фото. Актуальная вместимость: основной — 550 мест, орта (средний) — 144, кіші (малый) — 48–60 гостей по присланным меню. Работающий в Royal Palace пользователь 21 октября 2026 года уточнил, что названные им 144 места относятся к среднему залу, а не к малому. Это последнее исправление имеет приоритет над его прежней оговоркой о малом зале и старыми 500/140 местами в Instagram. Диапазон 48–60 для малого зала подтверждён меню, полученными 22 октября. История источников сохранена в `docs/asset-sources.md`.

Короткие запросы не читают и не меняют заполненную форму. Общий запрос не добавляет просьбу о просмотре без выбора пользователя. Если WhatsApp недоступен, текст можно скопировать; при запрете буфера обмена он выделяется для ручного копирования. Без JavaScript форма не отправляется, а быстрые ссылки содержат подготовленный текст. Цены меню и указанные услуги взяты из PDF; актуальность цен и обязательность доплат нужно уточнять у администратора.

На странице используются лёгкие локальные WebP-превью, в увеличении — JPEG-оригиналы. Фотографии принадлежат их правообладателям: источник — галерея Royal Palace в 2ГИС, сведения сохранены в `docs/asset-sources.md`. Перед публикацией согласуйте материалы и текст с владельцами. Заголовки оформлены шрифтом Forum, тексты и элементы управления — Golos Text. Шрифты размещены локально и распространяются под OFL; лицензии приложены рядом с файлами шрифтов.

Перед рабочим запуском: подтвердить контактный номер, актуальные фото и разрешения на использование, рассадку для конкретного события, актуальность меню и цен, обязательность доплат, окончательную смету, услуги, порядок просмотра и бронирования. Демо помечено в подвале и закрыто от поисковой индексации. Внешней публикации в этой задаче нет.

Текущее оформление — молочный фон, тёплый тёмный текст и золотые акценты. По последнему требованию пользователя фотографии с людьми не используются, включая фон и фрагменты людей; перед отбором проверяется исходник целиком.


## GitHub Pages

Адрес: https://luxaeternaaaa.github.io/royal-palace/

По просьбе пользователя репозиторий открыт для GitHub Pages. Публикация запускается автоматически после push в `master`; workflow `.github/workflows/pages.yml` проверяет синтаксис, запускает модульные/сборочные тесты, собирает `dist` и публикует только готовый сайт. Исходники, тесты, документация и локальные файлы не попадают в артефакт Pages.

Переменная `PUBLIC_BASE_PATH` берётся из конфигурации Pages. Для адреса проекта она добавляет `/royal-palace` к локальным URL только в сборке; исходный `public/` и локальный сервер остаются совместимыми с корнем сайта. Корневые и относительные импорты, внешние ссылки и бинарные материалы проверяются тестами `tests/public-base.test.mjs`.

Сборка добавляет общую версию содержимого к URL CSS/JS/MJS и вложенным импортам. После обновления сайта браузер получает согласованный набор кода, включая локализацию, вместо смеси нового HTML и старого модуля из кэша. Версия одинакова для LF/CRLF и меняется при изменении кода; исходники `public/` и медиа не переписываются. Проверки — `tests/asset-version.test.mjs`.

Варианты оформления доступны через «Дизайн». Третий вариант — «Изумрудная II». Отправка сообщения в WhatsApp по-прежнему выполняется самим посетителем.
