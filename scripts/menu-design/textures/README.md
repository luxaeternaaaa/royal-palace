# Фактура оригинальных меню

Четыре WebP извлечены из PDF брата пользователя от 22 октября 2026 года. Это фоновые слои самих документов, без текста, логотипа и орнаментов. Генерация изображений не использовалась.

| Файл | Оригинал | Цвет |
| --- | --- | --- |
| main.webp | 30.000 .pdf | Зелёный |
| middle.webp | 27 000.pdf | Кремово-золотой |
| small.webp | 27000.pdf | Бордовый |
| memorial.webp | .pdf | Тёмно-синий |

Исходные SHA-256 приведены в docs/menu-sources.md. В каждом PDF сохранены только первые три группы рисования фоновой формы: заливка и бумажная фактура. Буквенные и декоративные слои исключены. При рендеринге шириной 1600 px выбран участок (0,80)–(1600,2160), до видимого стыка тайлов исходника. Результат 1600×2080; детализация фактуры ограничена исходным JPEG 800×533.

render.mjs встраивает эти фоны в листы, сохраняя текст отдельными шрифтами до финального экспорта. Исходные PDF не меняются и не публикуются.

## Новогодние меню и выпускные

Четыре дополнительных фона извлечены из PDF, переданных 23 октября 2026 года. Оригиналы находятся в каталоге `WhatsApp Unknown 2026-10-23 at 23.53.23`. Текст, герб и рамки не включены; генерация и ретушь не использовались.

| Файл | Исходный PDF | Цвет |
| --- | --- | --- |
| newyear-main.webp | 45.000 .pdf | Бордово-красный |
| newyear-middle.webp | 40.000  (1).pdf | Насыщенный тёмно-синий |

| graduation.webp | 37000.pdf | Зелёный, светлее прежнего банкетного |

Сохранены первые три группы рисования фоновой формы: исходная заливка и два слоя бумажной фактуры. Xref формы: 30 для трёх новогодних источников, 1055 для выпускного. Рендер шириной 1600 px; участок (0,80)–(1600,2160) выбран до стыка бумажных тайлов. Каждый WebP имеет размер 1600×2080. Новые файлы не заменяют четыре прежних фона.

Манифест извлечения с SHA-256 оригиналов и контрольными размерами: `output/new-menu-pdfs/textures/manifest.json`; изображения для проверки находятся рядом. Зелёный фон выпускного отличается от `main.webp`, поэтому сохранён отдельно. На его самых светлых участках белый текст имеет контраст около 3.4:1: перед использованием мелкого светлого текста требуется затемнение фона и проверка готового листа.
