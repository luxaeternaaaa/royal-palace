Статическое приложение на HTML/CSS и нативных ES-модулях. React, Vite, серверного API, базы данных и системы бронирования нет. Формы и бюджет работают в браузере; черновики сохраняются локально. Node.js **22+**; единственная dev-зависимость — `@playwright/test` версии `1.64.1`.

### Запуск и проверки

```powershell
npm run dev
# http://localhost:4173/ — сервер должен продолжать работать
npm run check
npm run test:unit
npm run test:browser
npm run build
```

`npm start` также запускает сервер; `npm test` объединяет unit и браузерные тесты. При отсутствии зависимостей используется `npm ci` с существующим lock-файлом. Playwright сам выбирает отдельный свободный локальный порт; постоянный preview не заменяет его test-server.

Для проверки сборки по адресу репозитория в PowerShell:

```powershell
$env:PUBLIC_BASE_PATH = '/royal-palace'
try { npm run build } finally { Remove-Item Env:PUBLIC_BASE_PATH }
```

Это пересоздаёт `dist`, но не меняет `public`. Обычная сборка без переменной подходит для корня домена. Нельзя загружать на Pages исходный `public` с корневыми URL без обработки base path.

## Принятые решения

### Языки, темы и оформление

Три языка: RU/KK/EN. На русском — **Большой зал / Средний зал / Малый зал**, а не «Основной / Орта / Кіші». «Ас беру» сохраняется как термин. Язык и тема независимы; пользовательские пожелания не переводятся автоматически.

Три выбора дизайна: молочный (default), изумрудный и **Изумрудный II**. Значения `royal-palace-theme`: `classic`, `emerald`, `emerald-halls`; третий использует `data-theme="emerald"` и `data-layout="halls"`.

Изумрудная основа — ровный `#064734`, вторичные поверхности `#0A503D`/`#105B45`. Мех, фоновые картинки меха, анимация нитей, боковые полосы, растушёвки и декоративные радиальные градиенты отменены. Молочная палитра включает `#FBF9F4`, `#282521`, бронзу `#8A6A38`, кнопку `#D2B47C`; детали в DESIGN.md. Forum 400 — короткие заголовки/категории; Golos Text — основной текст и цены со знаком ₸, шрифты локальные.

В завершённом локальном hero шапка прозрачная, расположена поверх фотографии и не закрепляется при прокрутке. Исходный герб показан белым, без отдельного повторного wordmark; верхнего WhatsApp нет. Это актуальное решение для всех трёх дизайнов. Прежняя белая шапка относится к предыдущему опубликованному срезу `10bb12ff…`; её не нужно восстанавливать по историческим записям.

Пользователь требует человечную последовательность, минимум лишних текстов и точечную работу с пропорциями, цветами и удобством. Le Dome — референс карточек, фото-попапа и контактов; его бренд, тексты, услуги и фотографии не копируются.

### Залы и третий вариант

Вместимость: **550 / 144 / 48–60**. В отдельных банкетных меню большого зала ограничение до 500 гостей — это условие предложения, а не исправление вместимости.

В «Изумрудном II» три карточки: фото 4:3 → название → вместимость → компактная стрелка. Нажимается вся карточка; видимая подпись «Подробнее» убрана, доступное имя действия сохранено. Отдельный раздел «Внутри Royal Palace» и его навигационная ссылка скрыты только в третьем варианте, DOM и обычная галерея двух исходных вариантов сохранены.

Карточки открывают существующий нативный `#gallery-dialog`, **не inline-разворачивание**. Для большого зала — четыре фотографии, счётчик, боковые стрелки/клавиатура, две ссылки на видео зала через существующий плеер. Закрытие возвращает фокус карточке, закрытие вложенного видео — ссылке галереи. Действия меню/обращения закрывают галерею и фокусируют нужный раздел; черновики остаются в исходном DOM. Старый `#gallery` в этом варианте открывает большой зал, закрытие заменяет hash на `#halls`.

У среднего/малого нет подтверждённых интерьерных материалов. Пользователь разрешил одинаковую рамку с честной статичной заглушкой **«Фото пока нет»**, без чужих фото/видео. В диалогах остаются вместимость, приглашение на просмотр и полезные действия.

Большая карточка и первый кадр её галереи ссылаются на `public/assets/hall-main-centered.webp`: ретушированная ImageGen-производная подлинного `venue-hero.webp`, по просьбе выровнять кадр и убрать знак 2GIS. Оригинал сохранён; производная не выдаётся за нетронутый камерный оригинал. CSS-поворота нет. Новый hero использует отдельно присланный пользователем центрированный кадр и его `hero-centered-*` производные; это разные наборы файлов.

Фото и постеры остаются без людей. Для шести конкретных присланных роликов пользователь отдельно разрешил полный материал, включая людей; это не общее разрешение на любые фотографии с людьми.
